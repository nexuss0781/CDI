# CCT Performance Sprint Decision: 10,000 Training Token-Positions per Second

**Decision:** `PARTIAL_PERFORMANCE_EVIDENCE`

**Scope:** CCT Level 1 runtime validation for the retained `dcss_residual_cdi` model. This record evaluates only semantics-preserving execution improvements. It does not authorize a corpus, context, capacity, optimizer, precision, or quality-protocol change.

## Executive finding

The sprint produced a materially faster exact dense CPU execution path, but the requested **10,000 training token-positions per second** gate was not reached. The canonical compiled primary run measured **3,448.83 token-positions per second** at the registered length-16 workload. This is approximately **34.49% of the target** and remains slower than the matched GRU and Transformer references under the same eager CPU audit.

The result is therefore retained as `PARTIAL_PERFORMANCE_EVIDENCE`, not as a speed victory. The compiled path is eligible for further separately reviewed optimization work, but it does not authorize larger training or any language-quality claim.

## Primary result

| Measurement | Result |
|---|---:|
| Mean step time | 0.009279 s |
| Median step time | 0.009359 s |
| CDI throughput | **3,448.83 token-positions/s** |
| Requested gate | 10,000 token-positions/s |
| Gate attainment | 34.49% |
| Peak resident memory | 0.979 GiB |

The target shortfall is approximately **6,551.17 token-positions per second**. The result is not close enough to treat measurement noise or a minor tuning change as sufficient evidence for the requested gate.

## Secondary eager measurements

The secondary measurements used the same batch, tokenizer, optimizer, precision, and model, with the ordinary eager `causal_loss` path. They are diagnostic length-scaling measurements and are not substituted for the primary compiled gate.

| Model | Length 16 tok/s | Length 64 tok/s | Length 256 tok/s |
|---|---:|---:|---:|
| CDI, eager | 849.92 | 764.94 | 702.05 |
| GRU, eager | 3,567.53 | 3,420.51 | 2,482.42 |
| Transformer, eager | 7,386.50 | 9,622.93 | 5,484.52 |

The auxiliary measurements confirm that the CDI recurrence remains the runtime bottleneck under eager CPU execution. The compiled dense path improves the primary CDI result substantially over the eager measurement, but it does not reverse the ordering against either matched baseline.

## Retained implementation changes

The following changes passed the required equivalence and regression checks and are retained:

| Tier | Change | Evidence |
|---|---|---|
| P1/P2/P4 | Dense weighted four-vertex Laplacian, fused gate projections, cached band bounds, and reduced hot-loop allocations | Exact gate/state/output tests passed |
| P3 | Fixed dense-chunk compilation entry point through `forward_chunk_active` | Compiled forward-plus-backward benchmark completed |
| P4 | Flat stacked three-band recurrence and dense precomputation of token residuals | Deferred-path logits, state, loss, and gradient parity passed |
| Safety | Deferred spectral, geometry-energy, and state-norm checks | Metrics are accumulated in the recurrence and rejected after the chunk; ordinary eager mode retains fail-closed `FloatingPointError` behavior |
| Regression | Full repository suite | **304 tests passed** |

The fast path does not alter the DCSS equations, state layout, parameter values, tokenizer, vocabulary, quality data, training protocol, or validated CCT-G3.6 result. Named harmonic and unconstrained-cochain diagnostic configurations retain the structured fallback path rather than using the full-model flat kernel.

## Decision and transition

The performance sprint is complete with `PARTIAL_PERFORMANCE_EVIDENCE`. The validated implementation improvements remain on `master` because they preserve the correctness oracle and pass the full regression suite. The 10,000 token-position/s approval gate remains **unmet**.

No scale ladder, larger corpus run, context expansion, capacity expansion, English-domain claim, or fluency claim is unlocked by this record. Any further attempt to close the remaining gap must be separately profiled and reviewed under the same equivalence, fail-closed safety, memory, and end-to-end training-step requirements.
